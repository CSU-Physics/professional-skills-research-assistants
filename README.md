# Professional Skills for Research Assistants

Slide decks and Try it tools for the SemiAcademy micro-credential **Professional Skills for Research Assistants**, maintained by the CSU Semiconductor Team. The course itself runs in Canvas at https://www.semiacademy.org/courses/59, where each module page shows its slide deck and, for Modules 1, 2, 3 and 5, a Try it tool.

The files are static HTML, served with GitHub Pages from the `main` branch: https://csu-physics.github.io/professional-skills-research-assistants/

## Contents

- `slides/m1.html` to `slides/m8.html`: one deck per module, 11 slides each (title, learning outcomes, four decisions, worked scenario, weaker and stronger versions, why the stronger version works, remember, try it this week).
- `tryit/t1-thread.html`: Module 1, reply, reply all or new thread.
- `tryit/t2-email.html`: Module 2, pick the stronger message.
- `tryit/t3-report.html`: Module 3, weekly report builder.
- `tryit/t5-plan.html`: Module 5, plan a week.
- `index.html`: a plain list of the decks and tools.

## Design notes

- Every file is self-contained: inline CSS and JavaScript, no external requests, no cookies, no browser storage, no analytics. Nothing a learner types is saved or sent.
- Decks work with the keyboard (left and right arrows, Page Up and Page Down, Home and End, or the buttons), announce the slide number to screen readers, and print one slide per page. Without JavaScript, all slides appear in one column.
- The wording follows the Canvas module pages. When a module page changes, update the matching deck.
- The decks give general guidance only. They do not state any policy on pay, timesheet approval or ownership of project material.
